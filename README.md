# 个人主页

这是一个基于GitHub Pages的个人主页网站，用于展示个人基本信息、项目作品和技能。

## 功能特点

- 响应式设计，适配不同设备屏幕
- 现代、简洁的UI界面
- 包含个人信息、项目展示、技能介绍和联系方式
- 支持GitHub Pages部署

## 技术栈

- HTML5
- CSS3
- Font Awesome 图标库

## 如何部署

1. 将此仓库推送到GitHub
2. 在GitHub仓库设置中启用GitHub Pages
3. 选择部署来源为 `main` 分支
4. 等待部署完成，即可通过 `username.github.io/repository-name` 访问

## 自定义配置

- 修改 `index.html` 文件中的个人信息
- 修改 `CNAME` 文件中的自定义域名（如果使用）
- 根据需要调整 `styles.css` 文件中的样式

## 本地测试

直接在浏览器中打开 `index.html` 文件即可预览页面效果。
